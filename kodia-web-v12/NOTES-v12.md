# KODIA · demo multipàgina v12

## Arquitectura i enfoc SEO

Prototip estàtic en català, basat en v10 i en el brandbook. Les set pàgines tenen contingut separat i comparteixen recursos locals. El manteniment web s’ha integrat com una secció de la pàgina de Disseny web; ja no hi ha ruta pròpia.

| Pàgina | Focalització | Nota |
|---|---|---|
| Inici `/` | Portada general de disseny web, xarxes socials i SEO | No es força una keyword específica de disseny; el title/H1 són més amplis. Keyword paraigua pendent de recerca i d’encaix. |
| Disseny web `/serveis/disseny-web/` | **Disseny web Girona** | URL principal de disseny web local; paquets, preus i manteniment en una pàgina específica. |
| Xarxes socials `/serveis/xarxes-socials/` | Gestió de xarxes socials | Sense canvi de clúster ni volum als tres exports nous. Abast continua preliminar. |
| SEO `/serveis/posicionament-seo/` | Agència SEO Girona; posicionament web Girona; posicionament SEO Girona | Una sola URL per al clúster local; no es prometen posicions. |
| Projectes `/projectes/` | Sense clúster objectiu | Pàgina de confiança; conceptes de mostra, no casos reals. |
| KODIA `/agencia/` | Sense clúster objectiu | Pàgina institucional; el slug és provisional. |
| Contacte `/contacte/` | Sense clúster objectiu | Conversió; el canal real i el formulari estan pendents. |

El mapa detallat i l’anàlisi de solapament són a `SEO-MAP.md` i `KEYWORD-ANALYSIS.md`. Les xifres de volum, KD, CPC i competència són estimacions de SE Ranking dels exports facilitats; no són recerques observades, demanda de Girona ni rànquings de KODIA. Les variants català/castellà o repetides entre exports no s’han sumat.

## Contingut comercial

- La pàgina Disseny web mostra One Page 300 €, web corporativa des de 600 € i web a mida des de 900 €, sempre sense IVA. El preu habitual de 450 € no es mostra fins a validar-ne la base.
- El manteniment opcional apareix dins la pàgina Disseny web: allotjament, domini, HTTPS/SSL, suport per incidències i fins a tres petites edicions mensuals, comptades individualment i no acumulables. No es mostra tarifa perquè no està confirmada.
- Xarxes socials i SEO continuen sense preus. L’abast, canals, zona i lliurables continuen pendents; no s’hi prometen resultats.
- Contacte és demostratiu i no transmet consultes.
