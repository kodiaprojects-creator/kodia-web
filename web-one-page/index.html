Què és una Web One Page?

Una Web One Page és una pàgina web estructurada en diferents seccions dins d'una única URL.

L'usuari troba tota la informació sense haver de navegar per diferents pàgines.

Preguntes freqüents

Una Web One Page és suficient per al meu negoci?

Sí, si podem explicar tota la informació important en una sola pàgina clara i ben organitzada. Si tens molts serveis o necessites desenvolupar diferents temes amb més detall, t'ho direm i et proposarem una estructura amb diverses pàgines.

Què inclou una Web One Page?

Inclou l'estructura del contingut, la redacció i adaptació dels textos, disseny a mida, adaptació al mòbil, SEO bàsic, publicació i tres rondes de canvis.

Quant costa una Web One Page?

L'oferta actual és de 300 € sense IVA. El manteniment és opcional i costa 15 €/mes, sense IVA. Abans de començar t'explicarem què inclou el pressupost del teu projecte.

Quant trigueu a fer una Web One Page?

Habitualment, entre 7 i 10 dies un cop tenim la informació i el material necessaris per començar. Et confirmarem el calendari previst abans d'iniciar el projecte.

Podeu fer la web si encara no tinc els textos?

Sí. T'ajudem a ordenar la informació i a redactar o adaptar els textos. Per fer-ho, necessitarem que ens expliquis bé el negoci, els serveis i què vols transmetre.

Una Web One Page pot sortir a Google?

Sí. La web inclou SEO bàsic, però no et podem garantir una posició concreta als resultats de cerca. Si vols treballar diversos serveis o temes amb contingut propi, pot convenir-te una web amb pàgines separades.
