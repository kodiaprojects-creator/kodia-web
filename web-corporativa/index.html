Preguntes freqüents

Quan em convé una web corporativa en lloc d'una Web One Page?

Quan tens diversos serveis, molta informació o necessites explicar diferents temes en pàgines separades. Si tota la informació essencial del teu negoci es pot presentar clarament en una sola pàgina, una Web One Page pot ser suficient.

Què inclou una web corporativa?

Inclou una portada i fins a quatre pàgines interiors, estructura i textos, disseny a mida, adaptació al mòbil, SEO bàsic, publicació i tres rondes de canvis.

Quant costa una web corporativa?

El preu comença a 600 € sense IVA. El manteniment és opcional i comença a 25 €/mes, sense IVA. Et prepararem un pressupost concret segons l'estructura i les necessitats del projecte.

Quant trigueu a fer una web corporativa?

Habitualment, unes dues setmanes un cop tenim la informació i el material necessaris per començar. El termini concret dependrà de l'abast del projecte i te'l comunicarem a la proposta.

Podré ampliar la web més endavant?

Sí. Podem començar amb les pàgines que necessites ara i ampliar la web quan el negoci ho demani. Les pàgines noves, els canvis d'estructura i les funcionalitats addicionals es valoren i pressuposten a part.

Feu servir plantilles?

No partim de plantilles genèriques. Preparem l'estructura i el disseny de la web segons el negoci, els continguts i el que necessitem que hi pugui fer el visitant.
