Programació web a mida a Girona

Hi ha negocis que necessiten alguna cosa més que una web informativa: reserves, un gestor per editar els continguts, contingut que canvia sovint o connectar la web amb una altra eina.

En aquests casos, primer t'escolto i et dic amb sinceritat si de debò ho necessites o si una web corporativa ja t'ho resol. Si cal programar a mida, et passo una proposta tècnica i econòmica tancada abans de començar.

Els projectes a mida comencen a partir de 900 €, sense IVA.

Quan necessites una web a mida?

  • CMS personalitzat per editar continguts
  • Sistema de reserves
  • Contingut dinàmic que canvia sovint
  • Integracions amb altres eines
  • Automatitzacions del negoci

Un projecte adaptat a la teva necessitat

Des de 900 €, amb poc pes visual i sense sorpreses: abans de començar saps què inclou i què costa. Si només necessites una web per al teu negoci a Girona, mira també disseny web a Girona.

Preguntes

Preguntes freqüents

Quant costa una web a mida?

A partir de 900 € sense IVA. El preu final depèn de les funcionalitats i les integracions, i el manteniment, opcional, es pressuposta segons el projecte.

Fas botigues en línia?

No. No faig botigues en línia.

Necessito una web a mida o em basta una corporativa?

Si només has d'explicar serveis, horaris i contacte, una web corporativa sol ser suficient. La web a mida té sentit quan hi ha reserves, un gestor de continguts o connexions amb altres eines.

Com treballem el projecte?

Primer t'escolto i et dic si cal. Si sí, et passo una proposta tècnica i econòmica tancada abans de començar.

On treballeu?

Kodia és de Banyoles i fa webs per a tot Catalunya. Tot es fa a distància.
