# KODIA · demo multipàgina v12

Obre `index.html` per començar. Les pàgines i els recursos són locals i comparteixen navegació.

Pàgines: Inici, Disseny web (amb manteniment opcional integrat), Xarxes socials, Posicionament SEO, Projectes, KODIA i Contacte.

- `SEO-MAP.md`: arquitectura i clústers de keywords revisats amb els tres exports nous.
- `KEYWORD-ANALYSIS.md`: resum de mètriques, solapaments i font/fila dels exports.
- `COPY-DRAFT.md`: resum editorial actual. `COPY-DRAFT-v1-archive.md` conserva el primer esborrany d’Isra.
- `NOTES-v12.md`: abast, keywords, preus i estat de revisió.
- `VISUAL-REVIEW-v12.md`: revisió visual anterior i pendents.
- `assets/ATTRIBUTIONS.md`: procedència i llicència dels visuals.

És una demo estàtica: el formulari/contacte no envia missatges i el web públic no s’ha modificat.
