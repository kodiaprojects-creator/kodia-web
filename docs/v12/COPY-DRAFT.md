## Inici `/`

- **Focus:** portada general de KODIA i dels tres serveis; keyword paraigua no fixada.
- **Title:** KODIA | Disseny web, xarxes socials i SEO.
- **H1:** Web, xarxes socials i SEO per al teu negoci.
- **Funció:** presentar KODIA i derivar a les pàgines de servei.
- **Seccions recuperades:** «Com treballem» amb quatre passos (escoltem, definim, creem, revisem) i «Som KODIA» amb el text de marca de les captures.

## Disseny web `/serveis/disseny-web/`

- **Focus principal:** disseny web Girona; intenció de servei, opcions, preus i decisió de compra.
- **Title:** Disseny web Girona | Pàgines per a negocis | KODIA.
- **H1:** Disseny web a Girona, pensat per al teu negoci.
- **Contingut:** One Page, web corporativa, web a mida i manteniment opcional en aquesta mateixa pàgina.
- **Manteniment:** allotjament, domini, HTTPS/SSL, suport per incidències i fins a tres petites edicions mensuals; cada edició compta individualment i no s’acumula. Quota pendent de confirmar. Sense pàgina autònoma.
