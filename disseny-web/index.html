02 / Preguntes

Preguntes freqüents sobre el disseny web

Quin tipus de web em convé?

Si vols presentar el teu negoci o un servei en una sola pàgina i facilitar que et contactin, la Web One Page et pot encaixar. Si ofereixes diversos serveis i vols explicar-los amb una pàgina per a cadascun, et recomanem una web corporativa. Si necessites alguna funcionalitat específica, podem preparar-te una web a mida.

Què inclou el preu de cada web?

La Web One Page costa 300 € + IVA i la web corporativa parteix de 600 € + IVA. Totes dues inclouen textos, imatges, adaptació a mòbil, formulari de contacte, revisions i publicació. Les webs a mida parteixen de 900 € + IVA i es pressuposten segons les pàgines i funcionalitats que necessitis.

Quantes pàgines inclou la web corporativa? Quant costa afegir-ne una?

La web corporativa inclou sis pàgines en total: la portada i cinc pàgines independents. Una pàgina addicional costa entre 40 i 100 € + IVA, aproximadament, segons l’extensió i el contingut. Et confirmem el preu al pressupost.

Els preus inclouen l’IVA?

Tots els preus que mostrem són sense IVA, inclosos els extres i les quotes de manteniment. Al pressupost hi veuràs l’import total amb l’IVA inclòs.

Puc veure exemples de webs que heu fet?

Pots veure una selecció dels nostres treballs a l’apartat Projectes. Si hi ha algun exemple que t’agrada, ens el pots indicar quan ens expliquis què tens al cap per a la teva web.

Puc demanar pressupost sense compromís? Com es paga el projecte?

Sí. Explica’ns què fa el teu negoci i què necessites, i et prepararem un pressupost sense compromís. Si l’acceptes, el pagament es fa per transferència bancària, amb un 50% abans de començar i el 50% restant quan et lliurem el projecte.

Us encarregueu dels textos i les imatges?

Sí. Podem redactar els textos a partir del que ens expliquis sobre el teu negoci i els teus serveis. Si ens passes unes línies sobre cada servei, ens ajudarà a descriure’l amb més precisió i adaptar el text al web. Podem fer servir les teves fotografies o seleccionar imatges d’un banc d’imatges.

Podré revisar la web abans que es publiqui?

Sí. La One Page i la web corporativa inclouen tres rondes de revisió. Podràs veure la proposta, enviar-nos els teus comentaris i demanar ajustos abans de publicar-la.

Quant de temps trigareu a tenir la web llesta?

El termini de la One Page és de 7 dies laborables a partir del moment en què rebem tota la informació i els materials necessaris. Per a una web corporativa o a mida, et confirmem el termini abans de començar.

Si ja tinc web, puc aprofitar el domini i els continguts?

Podem connectar la nova web al domini que ja fas servir i revisar quins continguts vols aprofitar. També revisem les adreces de les pàgines actuals i, si canvien, configurem redireccions perquè els enllaços antics portin a les pàgines corresponents de la nova web. Si tens correu vinculat al domini, indica’ns-ho quan ens demanis pressupost per tenir-ho en compte durant el canvi.

La web inclou SEO?

Si vols donar més visibilitat a un servei concret o arribar a clients d’una zona determinada, explica’ns-ho quan ens demanis pressupost. Et detallarem quines tasques de SEO inclou la proposta i quines podem pressupostar a part.

El domini estarà al meu nom? Em podré endur la web?

Sí. El domini sempre queda al teu nom. Si el contractes amb el manteniment, nosaltres ens encarreguem de gestionar-lo. Si més endavant canvies de proveïdor, et pots endur la web i traslladar-la a un altre allotjament.

Podré editar la web jo mateix?

Si vols actualitzar directament textos, fotos o horaris, explica’ns quins continguts vols poder gestionar i ho concretarem a la proposta. Si prefereixes que ens encarreguem dels canvis, el manteniment inclou fins a tres petites edicions al mes.

És obligatori contractar el manteniment? Què inclou?

El manteniment és opcional. Costa 20 €/mes + IVA per a la One Page i 35 €/mes + IVA per a la web corporativa. Per a les webs a mida, concretem la quota segons el projecte.

Inclou el domini, l’allotjament, les còpies de seguretat, el certificat SSL, el suport per incidències i fins a tres petites edicions al mes.

Què compta com una petita edició?

Actualitzar un text, substituir una imatge o ajustar un color són exemples de petites edicions. Afegir una secció nova o canviar l’estructura de la web es pressuposta a part. Les edicions es compten per separat i les que no utilitzis durant el mes no s’acumulen.

Què passa amb el domini i l’allotjament si no contracto el manteniment?

Pots contractar el domini i l’allotjament directament amb el proveïdor que triïs. El cost dependrà de les seves tarifes i nosaltres ens encarregarem de publicar la web al teu allotjament i connectar-la al domini.
