02 / Preguntes

Preguntes freqüents

Quin tipus de web em convé?

Si vols presentar el teu negoci o un servei en una sola pàgina i facilitar que et contactin, la One Page et pot encaixar. Si vols dedicar una pàgina a cada servei, et recomanem una web corporativa. Si necessites funcionalitats específiques, podem preparar-te una web a mida.

Com demano pressupost i com es paga?

Explica’ns què fa el teu negoci i què necessites, i et prepararem un pressupost sense compromís. Si l’acceptes, el pagament es fa per transferència bancària, amb un 50 % abans de començar i el 50 % restant quan et lliurem el projecte.

Us encarregueu dels textos i les imatges?

Sí. Podem redactar els textos a partir del que ens expliquis. Si ens passes unes línies sobre cada servei, podrem adaptar millor el contingut al web. També podem fer servir les teves fotografies o seleccionar imatges d’un banc d’imatges.

Quant triga el projecte i quantes revisions inclou?

El termini de la One Page és de 7 dies laborables des que rebem tota la informació i els materials necessaris. Per a una web corporativa o a mida, et confirmem el termini abans de començar. La One Page i la web corporativa inclouen tres rondes de revisió.

Si ja tinc web, què puc conservar?

Podem connectar la nova web al domini que ja fas servir i aprofitar els continguts que vulguis conservar. Revisem les adreces de les pàgines actuals i, quan canvien, configurem redireccions perquè els enllaços antics portin a les pàgines corresponents de la nova web. Si tens correu vinculat al domini, indica’ns-ho per tenir-lo en compte durant el canvi.

La web inclou SEO?

Sí, el projecte inclou SEO bàsic. Si vols fer seguiment del posicionament de la web un cop publicada, pots contractar el servei de SEO a part.

El domini estarà al meu nom i em podré endur la web?

Sí. El domini sempre queda al teu nom. Si el contractes amb el manteniment, nosaltres el gestionem. Si més endavant canvies de proveïdor, et pots endur la web i traslladar-la a un altre allotjament.

Què passa si no contracto el manteniment?

Pots contractar el domini i l’allotjament amb el proveïdor que triïs. Nosaltres ens encarreguem de publicar la web al teu allotjament i connectar-la al domini.

03 / Opcional

També podem mantenir la web després de publicar-la

El manteniment és opcional. Si vols que KODIA s’encarregui de la continuïtat tècnica, pots afegir-lo a la proposta. Pensa que és com una assegurança de cotxe: quan tens problemes, hi som!

  • Allotjament i domini
  • Còpia de seguretat
  • HTTPS/SSL
  • Suport per incidències
  • Fins a tres petites edicions al mes, com ara canviar un text, substituir una imatge o ajustar un color. Les edicions es compten per separat i no s’acumulen

Els canvis d’estructura i les seccions noves es pressuposten a part.
