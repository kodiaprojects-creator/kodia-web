02 / Preguntes

Abast clar abans de començar

Quin tipus de web em convé?

Una One Page pot encaixar si vols presentar un negoci o servei en una sola pàgina. Si necessites explicar diverses àrees, pots valorar una web corporativa. Per a funcionalitats específiques, estudiem un projecte a mida.

Què inclou el projecte?

Inclou textos, imatges, adaptació a mòbil, formulari de contacte, revisions i publicació. El nombre de pàgines i les funcionalitats es detallen a la proposta abans de començar.

Quan estarà llesta la web?

La One Page té un termini de 7 dies des que rebem tota la informació i els materials necessaris. Per a webs corporatives i projectes a mida, concretem el termini segons l’abast.

Els preus inclouen IVA?

No. Els imports indicats són sense IVA.

03 / Opcional

També podem mantenir la web després de publicar-la

Si vols que KODIA s’encarregui de la continuïtat tècnica, pots afegir el manteniment a la proposta. Inclou allotjament, domini, HTTPS/SSL, suport per incidències i fins a tres petites edicions de contingut al mes. Les edicions es compten per separat i no s’acumulen. La quota i les condicions es concreten abans de començar.
